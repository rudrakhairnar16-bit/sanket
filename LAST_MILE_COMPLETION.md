This package includes persistent admin CRUD routes for departments, service packs and learning content, plus audit export and seeded demo data.

## Verification
Run after installing dependencies and configuring MongoDB:

- `npm install`
- `npm run typecheck`
- `npm run build`
- `npm run seed`
- `npm run test:e2e`
