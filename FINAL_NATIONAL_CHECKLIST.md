# SANKET — Final National Checklist

## Before the final demo

### Product
- [ ] Sahayak opens reliably
- [ ] Camera is square everywhere
- [ ] Hand guidance is visible
- [ ] Recognition states are understandable
- [ ] Unknown signs are not force-classified
- [ ] Clerk response visual aid works
- [ ] Audio is only sent to the intended receiver
- [ ] Interpreter fallback is clearly presented as a fallback

### Evidence
- [ ] Real camera dataset collected
- [ ] 20–50 samples/sign
- [ ] Multiple signers represented
- [ ] Train/validation/test split frozen
- [ ] Thresholds calibrated only on validation data
- [ ] Final test results recorded
- [ ] Confusion matrix reviewed
- [ ] Difficult sign pairs identified
- [ ] Negative/open-set samples tested where possible

### ISL validity
- [ ] Labels reviewed
- [ ] Meanings reviewed
- [ ] Visual assets reviewed
- [ ] Unvalidated assets remain clearly marked

### Research
- [ ] Research paper reviewed
- [ ] Literature review reviewed
- [ ] Dataset provenance checked
- [ ] References checked
- [ ] Claims match evidence

### Security
- [ ] No secrets in repository
- [ ] No private OpenCode prompt committed
- [ ] Developer routes protected/clearly scoped
- [ ] Camera/data retention behavior understood
- [ ] Production-only security gaps documented

### Presentation
- [ ] 2-minute demo rehearsed
- [ ] 5–6 minute demo rehearsed
- [ ] Judge Q&A rehearsed
- [ ] No fake deployment claims
- [ ] No fake accuracy claims
- [ ] Clear explanation of “AI when confident, human when necessary”

## Final principle

> **Evidence before claims. Reliability before features. Human fallback before pretending AI is perfect.**
