## Scholarly / research

3. Joshi, A., Agrawal, S., & Modi, A. (2023). **ISLTranslate: Dataset for Translating Indian Sign Language**. Findings of ACL 2023. https://aclanthology.org/2023.findings-acl.665/
   - Continuous ISL-English dataset; repository reports approximately 30k/31k sentence/phrase pairs.

4. Exploration-Lab. **ISLTranslate GitHub repository**. https://github.com/Exploration-Lab/ISLTranslate

5. K. Mallikharjuna Rao, H. Kaur, S. Kaur Bedi, & M. A. Lekhana. (2023). **Image-based Indian Sign Language Recognition: A Practical Review using Deep Neural Networks**. arXiv:2304.14710. https://arxiv.org/abs/2304.14710

6. **Indian Sign Language Detection Using Deep Learning**. IEEE conference publication. https://ieeexplore.ieee.org/document/10581347/

7. **Translating the unspoken: Deep learning approaches to Indian Sign Language recognition using CNN and LSTM networks**. IEEE conference publication. https://ieeexplore.ieee.org/document/10420379/

8. **Indian Sign Language Recognition: A Comparative Analysis Using CNN and RNN Models**. IEEE conference publication. https://ieeexplore.ieee.org/document/10245525/

9. **Accurate Gesture Recognition in Indian Sign Language Using Deep Learning**. IEEE ISCON 2025. https://ieeexplore.ieee.org/document/11340772/
